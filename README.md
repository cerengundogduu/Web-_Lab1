# Web-_Lab1
 # TechSphere Digital Studio

A 4-page website built strictly with semantic HTML5, without CSS or JavaScript.

## Theme
A fictional tech firm, **TechSphere Digital Studio**, specializing in modern web solutions, software architecture, and digital services.

## File Organization
* `index.html`: Main landing page with two `<article>` elements.
* `about.html`: Studio mission, `<figure>`, and semantic tags.
* `services.html`: Structured data table (`<thead>`, `<tbody>`, `<tfoot>`).
* `contact.html`: Accessible contact form with diverse input fields.
* `assets/`: Image resources.

## Challenges Faced
* Creating clear visual hierarchy purely through semantic HTML without CSS.
* Ensuring all relative paths work consistently across all pages.
